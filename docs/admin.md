# Админ-панель тестового сервера

Адрес:

```text
https://силенок.рф:4411/admin
```

Панель предназначена для быстрого тестирования ролей Android-приложения. После входа доступны:

- общий список устройств очевидцев и сотрудников;
- поиск по `device_id`, типу, платформе и роли;
- фильтр «Сотрудники / Очевидцы»;
- назначение ролей `inspector`, `administrator`, `chief`;
- снятие текущей роли.

Изменения выполняются через существующий `RoleService`, поэтому применяются серверные ограничения и сохраняется история ролей. Роль служебного Начальника, от имени которого работает панель, изменить в интерфейсе нельзя.

## Безопасность

- используется только HTTPS;
- пароль хранится на сервере как PBKDF2-SHA256-хеш;
- сессия подписана, имеет срок 8 часов и хранится в `HttpOnly`, `Secure`, `SameSite=Strict` cookie;
- изменяющие запросы защищены CSRF-токеном;
- страница входа ограничена по частоте запросов в Nginx;
- `/admin` закрыт на основном API-порту `4402` и доступен только на `4411`.

Пароль и служебные параметры запрещено добавлять в Git. Они задаются в `/etc/gibdd-backend.env`.
